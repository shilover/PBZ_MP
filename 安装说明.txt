影之刃零 双人联机 PvP 模组（PBZ_MP）{VERSION} —— 安装说明

======================================================================
【测试版（beta）】
功能还不完整，两台真实电脑之间还没有充分测试，可能出现掉线、判定不准、
甚至游戏崩溃。遇到问题请把下面"反馈问题"里说的文件发给作者。
本模组是玩家自制的非官方模组，与 S-GAME / 《影之刃零》官方、Valve 无关，
使用风险自负；建议先备份存档。

一、需要什么
------------
1. Steam 版《影之刃零》
2. UE4SS 的"影之刃零专用版"，下面两个都可以：
   - Nexus 版（测过 1.0.3）：https://www.nexusmods.com/phantombladezero/mods/5
   - KintaroModding 版（不是 UE4SS 官方主线版）：
   - 下载页：https://github.com/KintaroModding/ue4ss/releases/tag/v3.0.1-1195-g1ceefac8
   - 下载附件 phantombladezero_ue4ss_v3.0.1-1195-g1ceefac8.zip
     （同一页上的 UE4SS_*.zip 是通用版，别下错）
   - 整个解压到 <游戏目录>\platform\steam\
     解压后应该有 dwmapi.dll 和 ue4ss\ 文件夹
   - <游戏目录>：Steam 库里右键《影之刃零》→ 管理 → 浏览本地文件
3. Windows 10 / 11（不用另装 Python 或 .NET，系统自带的就够）


二、安装
--------
1. 把压缩包里的 PBZ_MP 文件夹整个放到：
       <游戏目录>\platform\steam\ue4ss\Mods\
   放好后应该是这样（目录结构会随版本变，认准这几个）：
       Mods\PBZ_MP\enabled.txt                 （有它 UE4SS 才会加载这个模组）
       Mods\PBZ_MP\fornet_lobby.dll            （联机程序，在游戏里运行，5 MB 左右）
       Mods\PBZ_MP\Scripts\                    （宿主 + 联机核：main.lua / fornet_*.lua）
       Mods\PBZ_MP\games\pbz\                  （游戏适配层）
       Mods\PBZ_MP\mods\base\                  （基础联机包：main.lua / 数值表 / 界面）
       Mods\PBZ_MP\mods\multi\  mods\spec\  mods\ranked\    （玩法 / 观战 / 排位，有就有）
       Mods\PBZ_MP\ext\steam\                  （Steam 联机扩展包，内测包有）
       Mods\PBZ_MP\net\                        （空文件夹：联机设置和状态写在这里）
       Mods\PBZ_MP\rec\                        （空文件夹：录制）
2. 有 enabled.txt 时 UE4SS 就会加载这个模组。保险起见，也可以打开
   Mods\mods.txt，加一行：
       PBZ_MP : 1

从旧版本升级：
- 直接覆盖。net\、rec\ 里是你的联机设置和录制，不用删
- 0.28.6 以前联机程序是单独的 PBZLobby.exe（更早叫"PBZ联机.exe"），现在用不到了，可以删掉
- 0.33.x 及以前的联机程序叫 pbz_lobby.dll，0.34 起改名 fornet_lobby.dll；旧的那份留着也不会被用，可以删
- 0.34 起目录分了层（Scripts\ 宿主、games\pbz\ 适配、mods\ 各玩法、ext\ 扩展包），升级请整个 PBZ_MP 文件夹覆盖，别只拷单个 lua


三、怎么联机
------------
1. 双方都启动游戏、读档（不在同一张地图也行，见第 6 步）
2. 在游戏里按 Home 打开联机面板，会出鼠标，按钮都能点
   （联机程序 fornet_lobby.dll 由模组在游戏里载入，不用另开程序，也不用管）
3. 面板顶上选"连接方式"，两边要选同一种：
   - 服务器大厅：要先有人架一台大厅服务器（见第九节），双方在面板"设置…"里
     填同一个服务器地址（默认是空的）。主机建房，客机在房间列表里点，
     或者"输入地址加入…"填房间号。
     加入时先直连；直连不通时，服务器开了中转、并且双方都在"设置…"里把
     "直连不通时用服务器中转"改成允许（默认不用），才走中转；否则就要
     主机在路由器上转发 UDP 端口 / 勾 UPnP，或者两边改用 Tailscale。
     服务器连不上时：主机在路由器上转发 UDP 端口（默认 27015，设置里可改，或勾 UPnP），
     客机点"输入 IP 直连…"填 主机公网IP:端口
     校园网 / 公司网等受限网络：这类网络往往进不来、也走不通服务器的中转，
     只能主动连出去。所以在受限网络的一方请让对方建房、自己去加入
   - 局域网：同一个路由器下；用 Tailscale / ZeroTier 等虚拟局域网也选这个
   - 本地 AI 对战：不联网，和电脑控制的对手打（练手用）
4. 主机建好房后，面板里点"复制我的地址 / 房间号"发给朋友
5. 第一次建房时 Windows 防火墙会弹窗，请点"允许"
6. 连上后对手会自动出现，客机会被传送到主机身边
   两边不在同一张地图时：客机连按两次 F1（或面板里点"前往主机所在地图"）切到主机那张地图，
   切图会先自动存档；主机在测试图等不在游戏地图列表里的地图时，只能手动过去
7. 双方各按 F1 准备 → 倒计时 → 先赢 2 回合获胜

可选：设置里可以填"联机密码"，两边填一样的就会给每个包签名；
密码不一致或一边没填时，面板会直接提示原因。


四、按键
--------
  Home    打开 / 关闭联机面板（开着时 Esc 或点"关闭"也能关；PgUp/PgDn 选、End 确定）
  F1      准备 / 取消准备；对局中 3 秒内连按两次 = 认输
  F2      把当前位置存为场地中心（以主机的为准）
  F6      藏起对手、回到单人
  F7 / F8 录制自己的动作 / 让对手回放（单人练习）
  F9      把状态写进日志（调试用）
  F12     手动造一个对手（测试用）
本模组不占用 F3 / F4 / F5。
如果同时装了第三方模组 Phantom Pact：它正在联机的期间本模组会自动暂停，
它断开后自动恢复（避免两个模组同时给对方生成角色）。


五、对局里要知道的
------------------
- 对局中双方锁血，被打倒不会真死，不会回篝火、不掉东西
- 暗杀、处决在对战里禁用
- 影之武装的伤害按 35% 算（蓄力终结技原本是打 Boss 用的，不削弱的话一拳能秒满血）
- 每局开始时会自动备份一次存档，在：
      ProjectPBZ\Saved\SaveGames\Steam\pbz-save-backups\

七、联机程序起不来（面板顶上红字 HELPER FAILED / 联机程序启动失败）
--------------------------------------------------------------------
0.34 起联机程序是游戏进程里的 fornet_lobby.dll，包里已经不带 PBZLobby.exe 了。
面板会直接写没起来的原因（被系统的应用控制策略拦住 / 缺少 fornet_lobby.dll /
这个 UE4SS 载入不了 DLL / 拉起 2 次都没响应）。0.34.8 及以前这里一律显示
"HELPER FAILED: no PBZLobby.exe"，那只是"连退路 exe 也不在"，不是真正的原因 —— 真正的原因
在 logs\<日期>\mp_probe.log 里带 "!!" 的那几行。
弹红字时叫你"重启游戏"是认真的：那次游戏里已经不再尝试载入这个 DLL 了，光点面板上的
"重新启动联机程序"不一定有用（新版会再试一次 DLL，但系统策略拦着还是失败），先重启游戏。

按这个顺序试：
1. 重启游戏。还这样再看下面。
2. Windows 11 的"智能应用控制"（公司 / 学校电脑则是"应用控制策略"）会拦未签名的
   DLL，日志里写的是"应用程序控制策略已阻止此文件"（错误 0x800711C7）。
   关掉它：设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 →
   智能应用控制 → 关闭（注意：关掉以后不能再打开，除非重装 / 重置 Windows）。
   公司或学校的电脑自己关不掉，只能找 IT。
3. 杀毒软件把 fornet_lobby.dll 删了 / 隔离了：确认 Mods\PBZ_MP 里有这个文件、
   大小 5 MB 左右；少了就从压缩包重新解压一份，并在杀软里放行。
4. 右键 fornet_lobby.dll → 属性 → 勾"解除锁定" → 确定，重启电脑再试。
5. 都不行：按第八节把日志发来。最关键是两样：logs\<日期>\mp_probe.log 里带 "!!"
   的行，和 net\lobby_errors.log（联机程序自己报的错，没有这个文件本身就是线索）。


八、反馈问题
------------
出问题时请记下大概的时间和当时在做什么（系统是 Win10 还是 Win11 也写一句），然后把这些发给作者：
  <游戏目录>\platform\steam\ue4ss\Mods\PBZ_MP\logs\<日期>\mp_probe.log   （模组日志，最重要；建不了 logs 文件夹时才会落在模组根目录）
  <游戏目录>\platform\steam\ue4ss\Mods\PBZ_MP\net\                        （整个文件夹，都是几十字节到几 KB 的 txt）
  <游戏目录>\platform\steam\ue4ss\UE4SS.log                               （UE4SS 日志）
  <游戏目录>\platform\steam\ue4ss\Mods\PBZ_MP\net\lobby_errors.log        （有就发：联机程序自己报的错）
  游戏崩溃时：<游戏目录>\platform\steam\ue4ss\ 里最新的 crash_日期_时间.dmp


九、自己架大厅服务器（可选，只有"服务器大厅"方式要用）
--------------------------------------------------------
服务端不随模组包提供，是单独的可选下载 PBZ_MP-{VERSION}-server.zip（Nexus 上叫 "Lobby Server"，GitHub Releases 里也有）。
解压出来是 server\ 文件夹，许可证 AGPL-3.0（见 server\LICENSE；模组其余部分是 GPL-3.0）。
改过的服务端给别人用，要向连上来的玩家提供改过的源码（AGPL 第 13 条）。
- 需要一台有公网 IP 的电脑或 VPS，装 Node.js 18 以上，不用 npm install
- 运行：node pbz-lobby-server.mjs --port 27020
- 中转默认关。打开：node pbz-lobby-server.mjs --port 27020 --relay
  中转能让打洞不通的玩家也连上，但每对玩家要占约 50 KB/秒（一小时约 180 MB）的流量
- 防火墙放行 UDP 27020 入站（是 UDP，不是 TCP）
- 玩家在联机面板 → 设置… → 大厅服务器 填 你的IP或域名:27020
详细说明见 server\README.md。
注意：服务器能看到连上来的玩家的公网 IP 和昵称（开了中转还会经手对局数据）；架服务器的人就是这个服务的
运营者，请遵守你所在地的法律，自己负责这些数据（服务端不写文件，但控制台日志会打出玩家的 IP 和房间名；
不想留日志就加 --quiet）。
