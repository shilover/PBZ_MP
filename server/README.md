# 4net 大厅服务器

[English](README.en.md)

"服务器大厅"连接方式用的服务端。只做三件事：

1. **房间列表**：主机每 2 秒登记一次（名字 / 地图 / 是否已满 / 局域网地址），10 秒没心跳自动删掉；客机拉列表
2. **介绍双方地址**：客机加入时，把双方的公网地址（服务器看到的 NAT 地址）和局域网地址互相告诉对方，两边自己打洞直连
3. **中转（默认关）**：可以只转观战流（`--relay-watch`），也可以用 `--relay` 把对局中转也打开：直连试 3 次都不通，客机请求中转，之后两边的状态包经服务器转发（每个会话每个方向限 120 包/秒，游戏是 30 包/秒）。没开时服务器回"没开中转"，客机面板提示"主机转发端口或用 Tailscale"，并一轮轮接着试直连。
   玩家自己也能决定用不用：面板"设置…"里的"直连不通时用服务器中转"（默认不用）。客机没允许就不请求中转；主机没允许时，登记房间时会告诉服务器，服务器拒绝给这个房间的会话中转（回 `hostnorelay`）。三方（服务器、主机、客机）都同意才会走中转

不跑游戏逻辑、不存盘，重启后房间由主机的心跳自己补回来。

联机程序**默认不填服务器地址**：想用"服务器大厅"，就自己架一台（或者用朋友架的），双方在联机面板 → 设置… → 大厅服务器里填同一个地址。

## 运行

中转分两个开关：`--relay` 两个都开（自建服务器照旧）；`--relay-watch` 只转观战流、**不转对局**；`--relay-match` 只转对局。客户端 0.34 起不再请求对局中转。

只要 Node.js（18 以上；用的全是自带模块，**不用 `npm install`**）：

```bash
node server/fornet-lobby-server.mjs                 # 默认 UDP 27020，监听所有网卡，IPv4 + IPv6（双栈）
node server/fornet-lobby-server.mjs --port 27020 --host 0.0.0.0 --quiet     # 只听 IPv4（旧行为）
node server/fornet-lobby-server.mjs --host 0.0.0.0,2001:db8::5              # IPv4 + 指定的一个 IPv6 地址（见下）
node server/fornet-lobby-server.mjs --relay          # 打开中转（默认关）
```

也可以用环境变量 `PORT` / `HOST`（0.34 起中转只认命令行参数，不再认 `RELAY=1`）。

**IPv6**：默认 `--host ::` 一个端口同时收 IPv4 和 IPv6（系统开不了 IPv6 时自动退回只听 IPv4）。域名加一条 AAAA 记录，只有 IPv6 的玩家就能连。
**机器有好几个公网 IPv6 地址时**别用默认的 `::`：系统回包时自己挑源地址，可能不是玩家发过去的那个，玩家的路由器 / 防火墙会把回包当陌生包丢掉。
这时写 `--host 0.0.0.0,<AAAA 指向的那个 IPv6>`（逗号分开，每个地址一个 socket，回包从收到的那个出去）。

**要不要开中转**：中转几乎是服务器全部的带宽——直连成功时服务器只有心跳和列表；每对走中转的玩家约 50 KB/秒（0.4 Mbps，一小时约 180 MB）。打洞在对称型 NAT / 运营商级 NAT（国内移动网络、没有公网 IP 的宽带常见）、公司 / 学校网络下容易失败，这些玩家没有中转就只能让主机开端口转发 / UPnP，或者改用 Tailscale。只给几个朋友用、带宽够的话可以开；放到公网给陌生人用，建议关着，免得流量费失控。每分钟打一行统计（房间数、会话数、收包、转发、丢弃）。

## 服务器自己开房（M5，默认关）

服务器可以自己开一个房间，不依赖任何玩家开房：名单 / 编号 / 规则 / 开始结束 / 计分 / 聊天 / 观战都由服务器管；玩家之间仍由服务器介绍后直连互发状态，打不通时经服务器中转（要 `--relay`）。支持 1v1（解说式，1 号当对局主机）和多人混战（`mpm=` 由服务器发）。

```bash
node server/fornet-lobby-server.mjs --room 1v1 --room-id SRV1V1 --relay
node server/fornet-lobby-server.mjs --room mp --room-size 4 --relay \
     --room-tl 180 --props "p1@0,0,0;p2@1000,0,0" --pick-range 5
```

| 参数 | 说明 |
|---|---|
| `--room 1v1` / `--room mp` | 开服务器房；不写就不开（默认关） |
| `--room-id` / `--room-name` / `--room-map` | 房间号 / 列表名字 / 地图名 |
| `--room-size` | 多人房人数（默认 4，2–16） |
| `--room-rules` | 26 项规则串（`bar=2;bo=3;dm=150;…`），不写用默认 |
| `--room-tl` | 比赛时限（秒） |
| `--props` / `--pick-range` | 可捡道具的位置 `id@x,y,z;…` / 允许捡的距离 |
| `--cfg` | 数值表（和普通大厅同一套 `CFGQ` 下发） |

### 服务器房鉴权 / 限速（默认开）

服务器房里的每个玩家加入时，服务器发一个随机**会话口令**（`SHOST` 第 7 段，16 位；只发给本人）。之后玩家发的状态包（`SSTATE`）、服务器中转（`SRLY` / `SRELAY`）、低频上报 / 捡道具（`SREPORT`）、聊天（`SCHAT`）、离开（`SLEAVE`）都要带这个口令，而且必须从**加入时的来源端点**发出。口令对不上、换了端点又没重新握手、不在这个房间的一律丢弃并计数（日志 `[room-sec]`）。**旧版联机程序没有口令，进服务器房后上报 / 聊天 / 中转都会被丢，等于不能用**（服务器房是 M5 才有的新功能）；普通大厅 / 排位 / 观战的老协议没有改，旧版照常。

NAT 换了公网端口时，客户端用 `JOIN` 第 6 段带旧口令重新握手，服务器认成同一个人、只更新端点，不重新分配编号。

每个来源端点按消息类型做令牌桶（容量 = 每秒上限，允许 1 秒突发）；持续超过 `--sban-drops` 次（在 `--sban-window` 秒内）临时拉黑 `--sban-sec` 秒，到期自动恢复。日志每个端点每分钟最多一行（`--quiet` 时 5 分钟一行），只写房间号 / 端点（`--quiet` 只写 IP 前两段）/ 原因 / 累计计数，不写聊天内容。

| 参数 | 默认 | 说明 |
|---|---|---|
| `--srate-state` | 60 | 每端点每秒状态包（游戏 30 包/秒） |
| `--srate-relay` | 60 | 每端点每秒 `SRLY` 中转包（游戏 30 包/秒） |
| `--srate-chat` | 3 | 每端点每秒聊天 |
| `--srate-pick` | 5 | 每端点每秒捡道具上报 |
| `--srate-report` | 20 | 每端点每秒 `SREPORT`（客户端 4 次/秒） |
| `--srate-join` | 10 | 每端点每秒 `JOIN`（客户端 1 次/秒） |
| `--srate-srelay` | 10 | 每端点每秒 `SRELAY` 请求（客户端 5 秒一次） |
| `--smax-packet` | 1400 | 服务器房单包字节上限（含头；状态包约 0.9 KB） |
| `--sban-drops` | 100 | 一个端点在窗口内被限速丢弃多少次后拉黑 |
| `--sban-window` | 10 | 上面这个计数窗口（秒） |
| `--sban-sec` | 30 | 临时拉黑多少秒（0 = 不拉黑） |

这些参数也认环境变量 `FORNET_SRATE_STATE` / `FORNET_SBAN_DROPS` 等（名字 = 参数去掉 `--`、`-` 换 `_`、加 `FORNET_` 前缀）。只影响 `--room` 服务器房；普通大厅的 `RELAY_RATE` / `WATCH_RATE` / 举报限速照旧。

**服务端和联机程序要一起换**：新版联机程序碰到旧服务端（`SHOST` 没有第 7 段口令）时口令为空，`SSTATE` / `SRLY` / `SRELAY` 还能靠旧服务端的旧格式解析凑合，但聊天会多一个空段、`SREPORT` / 捡道具的字段会错位；旧服务端也没有鉴权 / 限速。部署时先换服务端、再让玩家更新联机程序，或者反过来都行，但不要长期混用。

玩家在联机程序里用"加入房间"进这个房（命令行 `--join-room <房间号>@<服务器>`），不需要桥接平台；公开版 `FornetLobby-release.exe` 也能用。服务器只核对玩家上报的数据（比赛计时、双方上报的倒下 / 击杀、捡道具的距离和先后），不跑游戏，也不看玩家画面。观众用现有"观战"进房（服务器房不要求 `--relay` 也能看，转发是低频的 4 次/秒）。

## 和别的服务器互通房间（`--upstream`）

```bash
node server/fornet-lobby-server.mjs --upstream other.example.com:27020   # 可以写多个 --upstream
```

**只要你这台（A）配置对方（B）的地址，B 什么都不用改。** A 每 2 秒：

- 把自己登记的房间推给 B（B 像收普通主机登记一样收下，10 秒没再推就删）
- 像客户端一样向 B 拿列表（B 自己的房间 + 别人推给 B 的）

于是连 A 的玩家能看到 B 的房间，连 B 的玩家也能看到 A 的房间，列表里标 `[互通]`。
加入别的服务器的房间时，客机**直接去房间所在的那台服务器**加入（打洞介绍和中转都由那台做：主机的路由器只给它自己那台服务器开了口子）。
A 只推自己的房间，从 B 拿回来的列表里有 A 自己推过去的就跳过，不会兜圈；每个来源最多收 200 个房间。

注意：B 会接受任何人推来的房间（和任何人都能登记房间一样），所以列表里可能出现别人推来的假房间——点了这种房间，客机会去它声称的"所在服务器"加入，那台服务器就能看到这个玩家的公网 IP（和直连 IP 方式本来就会暴露的一样），列表也可能被刷。以后需要的话可以给 B 加一个"只收这些服务器的推送"的白名单。

## 排位封禁名单（`--bans`）

```bash
node server/fornet-lobby-server.mjs --ranked ranked.json --bans bans.txt   # 排位封禁名单
# 排位模块不在本仓库：默认找本文件同目录的 ranked.mjs，也可以 --ranked-module <路径> / 环境变量 RANKED_MODULE 指定
```

也可以用环境变量 `FORNET_BANS`。

- **封禁名单**（只管排位）：一行一个排位 pid（本地密钥的哈希，排行榜后台能看到），`#` 后面是注释，改了文件 5 秒内自动重读。名单里的人登记 / 加入排位房间都回 `banned`。普通房间不管。**0.34 起不再按平台账号 ID 封**：服务器不存任何桥接平台标识。
- **举报功能 0.34 整个去掉了**：没有 `--reports` / `--dump-reports`，服务器不收 `REPORT` 包，也不再有 `evidence/`。玩家有问题直接联系服务器的运营者；拉黑是本机的事（客户端 `blacklist.txt`，只存哈希）。
- 旧的 `reports.jsonl` / `evidence/` 若还在服务器上，请删除（没有用途就不该留）。

## 部署

自己架需要：

- 一台有公网 IP 的服务器（能装 Node.js 18+）
- 防火墙 / 云安全组放行 **UDP 27020**（或你选的端口）入站。**是 UDP，不是 TCP**，nginx 反代用不上
- 用 systemd 之类的常驻（参考下面）

```ini
# /etc/systemd/system/fornet-lobby.service
[Unit]
Description=4net lobby server
After=network.target

[Service]
ExecStart=/usr/bin/node /opt/fornet-lobby/fornet-lobby-server.mjs --port 27020
Restart=always
User=nobody

[Install]
WantedBy=multi-user.target
```

然后玩家在游戏内联机面板 → 设置… → 大厅服务器 填 `服务器IP或域名:27020`（端口是 27020 时可以省略）。

流量估算：直连成功时服务器只有心跳和列表，几乎没流量；开了中转时，每对走中转的玩家双向各 30 包/秒，每包几百字节，合计约 50 KB/秒。
本机只在 Node 24 上跑过（Windows），Linux / 其他 Node 版本没试。

## 协议

见 `fornet-lobby-server.mjs` 文件头。文本 UDP 包，`4N|…` 是控制消息，`4NR|<会话号>\n<状态包>` 是中转数据。

## 协议名字

上面写的 `4N|` / `4NR|` / `FORNET_` 是 4net 的中性名。已经有玩家在用另一套名字的游戏（比如控制包叫 `XYZS|`、对端包叫 `XYZHELLO`），
服务端要和它的联机程序（`lobby/WireTag.cs` 的 `Configure`）用同一套，两种办法：

- 启动时给 `--wire-server XYZS --wire-peer XYZ`（再加 `--wire-alias 4N` 让中性名的客户端也能连，回包用对方来时的那个）；
- 或者游戏自己的发布脚本把文件里标着 `@wire-defaults` 的那一行（`WIRE_DEFAULTS`）整行换成自己的默认值再发（环境变量前缀、排位模块文件名、服务器房默认地图名也在这一行），部署时就不用记参数。
