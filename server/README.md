# PBZ_MP 大厅服务器

"服务器大厅"连接方式用的服务端（设计和测试记录见 `docs/HANDOVER.md` §47）。只做三件事：

1. **房间列表**：主机每 2 秒登记一次（名字 / 地图 / 是否已满 / 局域网地址），10 秒没心跳自动删掉；客机拉列表
2. **介绍双方地址**：客机加入时，把双方的公网地址（服务器看到的 NAT 地址）和局域网地址互相告诉对方，两边自己打洞直连
3. **中转（默认关，`--relay` 打开）**：直连试 3 次都不通，客机请求中转，之后两边的状态包经服务器转发（每个会话每个方向限 120 包/秒，游戏是 30 包/秒）。没开时服务器回"没开中转"，客机面板提示"主机转发端口或用 Tailscale"，并一轮轮接着试直连。
   玩家自己也能决定用不用：面板"设置…"里的"直连不通时用服务器中转"（默认不用）。客机没允许就不请求中转；主机没允许时，登记房间时会告诉服务器，服务器拒绝给这个房间的会话中转（回 `hostnorelay`）。三方（服务器、主机、客机）都同意才会走中转

不跑游戏逻辑、不存盘，重启后房间由主机的心跳自己补回来。

联机程序**默认不填服务器地址**：想用"服务器大厅"，就自己架一台（或者用朋友架的），双方在联机面板 → 设置… → 大厅服务器里填同一个地址。

## 运行

只要 Node.js（18 以上；用的全是自带模块，**不用 `npm install`**）：

```bash
node server/pbz-lobby-server.mjs                 # 默认 UDP 27020，监听所有网卡
node server/pbz-lobby-server.mjs --port 27020 --host 0.0.0.0 --quiet
node server/pbz-lobby-server.mjs --relay          # 打开中转（默认关）
```

也可以用环境变量 `PORT` / `HOST` / `RELAY=1`。

**要不要开中转**：中转几乎是服务器全部的带宽——直连成功时服务器只有心跳和列表；每对走中转的玩家约 50 KB/秒（0.4 Mbps，一小时约 180 MB）。打洞在对称型 NAT / 运营商级 NAT（国内移动网络、没有公网 IP 的宽带常见）、公司 / 学校网络下容易失败，这些玩家没有中转就只能让主机开端口转发 / UPnP，或者改用 Tailscale。只给几个朋友用、带宽够的话可以开；放到公网给陌生人用，建议关着，免得流量费失控。每分钟打一行统计（房间数、会话数、收包、转发、丢弃）。

## 和别的服务器互通房间（`--upstream`，HANDOVER §50）

```bash
node server/pbz-lobby-server.mjs --upstream other.example.com:27020   # 可以写多个 --upstream
```

**只要你这台（A）配置对方（B）的地址，B 什么都不用改。** A 每 2 秒：

- 把自己登记的房间推给 B（B 像收普通主机登记一样收下，10 秒没再推就删）
- 像客户端一样向 B 拿列表（B 自己的房间 + 别人推给 B 的）

于是连 A 的玩家能看到 B 的房间，连 B 的玩家也能看到 A 的房间，列表里标 `[互通]`。
加入别的服务器的房间时，客机**直接去房间所在的那台服务器**加入（打洞介绍和中转都由那台做：主机的路由器只给它自己那台服务器开了口子）。
A 只推自己的房间，从 B 拿回来的列表里有 A 自己推过去的就跳过，不会兜圈；每个来源最多收 200 个房间。

注意：B 会接受任何人推来的房间（和任何人都能登记房间一样），所以列表里可能出现别人推来的假房间——点了这种房间，客机会去它声称的"所在服务器"加入，那台服务器就能看到这个玩家的公网 IP（和直连 IP 方式本来就会暴露的一样），列表也可能被刷。以后需要的话可以给 B 加一个"只收这些服务器的推送"的白名单。

## 部署

自己架需要：

- 一台有公网 IP 的服务器（能装 Node.js 18+）
- 防火墙 / 云安全组放行 **UDP 27020**（或你选的端口）入站。**是 UDP，不是 TCP**，nginx 反代用不上
- 用 systemd 之类的常驻（参考下面）

```ini
# /etc/systemd/system/pbz-lobby.service
[Unit]
Description=PBZ_MP lobby server
After=network.target

[Service]
ExecStart=/usr/bin/node /opt/pbz-lobby/pbz-lobby-server.mjs --port 27020
Restart=always
User=nobody

[Install]
WantedBy=multi-user.target
```

然后玩家在游戏内联机面板 → 设置… → 大厅服务器 填 `服务器IP或域名:27020`（端口是 27020 时可以省略）。

流量估算：直连成功时服务器只有心跳和列表，几乎没流量；开了中转时，每对走中转的玩家双向各 30 包/秒，每包几百字节，合计约 50 KB/秒。
本机只在 Node 24 上跑过（Windows），Linux / 其他 Node 版本没试。

## 协议

见 `pbz-lobby-server.mjs` 文件头。文本 UDP 包，`PBZS|…` 是控制消息，`PBZR|<会话号>\n<状态包>` 是中转数据。
