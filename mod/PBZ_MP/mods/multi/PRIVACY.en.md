# Game mode "multi" privacy notice

Applies only when this game mode (mods\multi\) is installed. Generated by `tools/gen_privacy.py` from `mod/PBZ_MP/mods/multi/init.lua`; identical to its row in-game (system settings → game modes), where you agree / withdraw; the panel's privacy page lists it too.

## Multiplayer rooms (`mp`, text version 2)

- In a multiplayer room you connect directly to every other player, so everyone in the room (not just the host) can see your IP address. To prevent this, turn on "Multiplayer: hide my IP" in the online panel's system settings (lobby server): only the host knows it and your traffic to the others goes through the host (higher latency; a new host learns it if the host changes). Over a bridge, see the bridge extension's notice.
- In duel mode, while you are playing, your match data (position, moves, health / energy, outfit, quick phrases) is forwarded to the spectators in the room.
