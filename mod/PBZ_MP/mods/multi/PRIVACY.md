# 玩法 mod「多人」隐私说明

只在装了这个玩法 mod（mods\multi\）时适用。本文由 `tools/gen_privacy.py` 从 `mod/PBZ_MP/mods/multi/init.lua` 生成，和游戏里"系统设置 → 已装的玩法 → 多人"那一栏逐字一致；同意 / 撤回都在那里，联机面板的"隐私说明"页也会列出。

## 多人房间（`mp`，文案版本 2）

- 多人房间里，你会和房里每一位玩家直接互连，所以房里所有玩家（不只是房主）都能看到你的 IP 地址。不想让别人看到：在联机面板的系统设置里开"多人房隐藏我的 IP"（服务器大厅），这样只有房主知道，你和其他人之间的包经房主转发（延迟会高一些；房主换人时新房主会知道）。经桥接方式连接时见桥接扩展包的说明。
- 对决模式里你上场时，你的对局数据（位置、出招、血量 / 杀气、装备外观、快捷语）会经转发机发给房里的观众。
