# 玩法 mod「观战」隐私说明

只在装了这个玩法 mod（mods\spec\）时适用。本文由 `tools/gen_privacy.py` 从 `mod/PBZ_MP/mods/spec/init.lua` 生成，和游戏里"系统设置 → 已装的玩法 → 观战"那一栏逐字一致；同意 / 撤回都在那里，联机面板的"隐私说明"页也会列出。

## 观战（`spec`，文案版本 1）

- 装了观战时，1v1 房间可以有观众：你上场对局时，房主会把你的对局数据（位置、出招、血量 / 杀气、装备外观、快捷语）和昵称转发给房里的观众；你观战时，会收到两位选手的这些数据。观众只和房主相连，看不到你的 IP 地址。
