# Game mode "spec" privacy notice

Applies only when this game mode (mods\spec\) is installed. Generated by `tools/gen_privacy.py` from `mod/PBZ_MP/mods/spec/init.lua`; identical to its row in-game (system settings → game modes), where you agree / withdraw; the panel's privacy page lists it too.

## Spectating (`spec`, text version 1)

- With spectating installed, a 1v1 room can have spectators: while you play, the host forwards your match data (position, moves, health / energy, outfit, quick phrases) and your name to them; while you spectate, you receive this data from both players. Spectators connect only to the host and do not see your IP address.
