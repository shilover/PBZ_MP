# PBZ_MP privacy notice

For v0.34.3. Generated by `tools/gen_privacy.py` from the CONSENT table in `fornet_ui.lua`; identical to the in-game prompts. Do not edit by hand.

This is a third-party online mod for a single-player game. Until you agree to one of the items below it sends nothing that identifies you (the only exception is the identifier-free availability query described at the end).

Each item below is asked once in-game the first time it is needed; your answer is stored in net\rules.txt on your PC and asked again if the text changes.

The lobby server is whichever address is set in system settings (the server software is open source; anyone can run one); the bundled server software stores no external-service account identifiers and logs only the first two octets of addresses.

## What each consent covers

### Playing online (`play`, text version 1)

- While playing online, your position, moves, health / energy, outfit and quick phrases are sent to the opponent, each packet tagged with a random install id generated on this PC (net\uid.txt; only for blocking / recent players, not a platform account);
- the host's room rules and stat table apply for this match only (not saved);
- a local 'recently played with' entry is kept on your PC only (auto-deleted after 30 days).

### LAN (`lan`, text version 1)

- LAN mode broadcasts your name, room name and map to the local network.

### Lobby server (`server`, text version 2)

- Once connected, the mod registers your name, install-id hash, room name and map on this server; it can also see your IP address. The server only introduces both sides for a direct connection; match traffic does not pass through it. If the host allows spectators, the spectator stream is relayed by it.
- The server software is open source and anyone can run one. The mod cannot verify who runs this server, how it handles this data or whether it is safe, and takes no responsibility for it.
- Only connect to servers whose origin you know and trust. You will be asked again if the address changes. By choosing Agree you confirm that you understand and accept the risk of connecting to this server.

### Fetch the server table (`cfg_fetch`, text version 1)

- Downloads a stat table (standard stats + weapon balance; numbers only, no code) from the lobby server;
- it is saved locally as net\srvcfg.txt and used in later matches.

### UPnP (`upnp`, text version 1)

- UPnP opens a port mapping (UDP, the helper's port) on your router; it is removed when you turn it off.

## Local data and deletion

- Kept on this PC: net\history.txt (recently played with, 30 days), net\blacklist.txt (hashes only), net\netcfg.txt (recent addresses), net\*.log.
- Clear history from the 'Recently played with' page; unblock from the 'Block / blacklist' page; deleting the net\ folder clears everything.
- There is no in-game reporting; contact the admin of the server you use about cheating / harassment.
- Safe mode (system settings) keeps only LAN / local AI, connects to no server and never touches any external online service.
- This mod is a non-commercial, fan-made project: open source, free of charge, no paid services, contains no game assets, does not alter paid content or bypass any protection. It is not a product of the game developer or any platform holder and is unaffiliated with them. If the developer or a rights holder asks, the author will take it down or change it.

The mod has no remote switch or status flag and never asks the server for one; when the server is unreachable it falls back to LAN / local AI. Extensions (the ext\ folder) are their authors' responsibility; any data they send also needs your consent first. Their consent items are not in this notice: see each extension's own folder (ext\<name>\PRIVACY.md) and its page in-game (system settings → extensions).
